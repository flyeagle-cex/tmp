# JiangnanProject

新文科比赛网页中的江南五城 Unity 城市文化交互模块。

## 当前版本

- 9:16 竖屏，默认分辨率 1080×1920
- 中英文切换
- 扬州、淮安、无锡、苏州、南京五城目录
- 城市页面可返回目录
- 视频语速默认 1.0×，支持 0.75× / 1.0× / 1.25× / 1.5× 循环调节
- 保留原始视频、视觉与答题流程

## 直接运行

进入 `Builds/Windows`，运行 `JiangnanProject.exe`。请完整保留该目录中的数据文件和依赖目录。

## Unity 源代码

使用 Unity `6000.3.22f1` 打开仓库根目录。项目源代码位于 `Assets`，配置位于 `Packages` 和 `ProjectSettings`。

仓库使用 Git LFS 管理视频及 Windows 构建资源。克隆前请确认已安装 Git LFS。

## 验收

`QA` 目录保留最终构建、竖屏运行和语速切换验收结果。
